NeptunePlayer

this project was entirely vibecoded but lots of thought put into it. hours and hours of tackling the code and trying to make it overall function & look like a normal app would.
at the start it really just was a small passion project that was a browser web-app but i wanted to make it more but also function the same no matter what platform you use
for desktop app i switched to electron and rewrote all the browser parts of the app and it is now polished!
(even if it is still buggy and WIP i still love it enough to release it and you can report using the neptune logo settings <3).
